          Orquestación Enterprise
          
Arquitectura del Sistema & Flujos n8n

          
Estructura modular orientada a eventos con 3 workflows en n8n, contratos de datos estrictos y persistencia en la nube de Oracle.

        

      


      
      

        

          🌐
          Diagrama Integral de Arquitectura (End-to-End)
        

        

          
        

      


      
      

        
        

          WF1 · Core Ingesta v1.8
          
WF1: Ingesta, Validación y Generación

          

            Procesa interacciones comunitarias, valida esquemas JSON, ejecuta inferencia semántica con Groq LPU (openai/gpt-oss-120b), calcula score_final = 0.75 × score_llm + 0.25 × peso_tipo y bifurca hacia Google Sheets.
          

          
    
            
  • Nodos: 24 nodos n8n
    • 
            
  • Disparador: Webhook JSON / Manual Trigger
    • 
            
  • Modelos: Groq API (openai/gpt-oss-120b, JSON estricto)
    • 
            
  • Salida: Google Sheets (Curaduria: pendiente)
    • 
          

          
            📥 Descargar WF1 JSON (v1.8)
          
        


        
        

          WF2 · Persistencia OCI v1.4
          
WF2: Curaduría hacia OCI Object Storage

          

            Monitorea el Sheet y, solo cuando decision = aprobado y está sin procesar, emite una solicitud PUT HTTP autenticada vía Pre-Authenticated Request (PAR) al bucket en Oracle Cloud.
          

          
    
            
  • Nodos: 14 nodos n8n
    • 
            
  • Disparador: Polling periódico / Disparo asistido
    • 
            
  • Autenticación: Pre-Authenticated Request (PAR) + HTTP PUT
    • 
            
  • Ruta Objeto: activos/aprobados/{execution_id}/{asset_id}.json
    • 
          

          
            📥 Descargar WF2 JSON (v1.4)
          
        


        
        

          WF3 · Observabilidad v1.2
          
WF3: Métricas Diarias & Auditoría Descartes

          

            Cron diario que consolida el total de activos, tasa de aprobación humana, reconciliación con OCI y desglose clasificado de descartes auditados hacia las pestañas de Power BI.
          

          
    
            
  • Nodos: 8 nodos n8n
    • 
            
  • Disparador: Cron 00:00 UTC Diario
    • 
            
  • Pestañas Sheet: Metricas_diarias & Metricas_descartes_diarias
    • 
            
  • Consumo: Power BI Desktop (DAX: MAX fecha)
    • 
          

          
            📥 Descargar WF3 JSON (v1.2)

          Rúbrica de Evaluación Oficial
          
Matriz de Cumplimiento de Criterios (Hackathon ONE)

          
Detalle y trazabilidad punto a punto de cada requerimiento del desafío oficial de Oracle Next Education & Alura.

        

      


      

        

          

            
              

                Criterio del Hackathon
                Estado
                Implementación Técnica en CommunityLab
              

            
            
              

                1. Ingestión funcional de interacciones
                ✅ Cumplido
                Normalización en n8n mediante estructura unificada con autor, canal, texto, timestamp UTC y ID determinístico CL-YYYYMMDD-XXX (Webhook JSON y Manual Trigger).
              

              

                2. Análisis de sentimiento y extracción LLM
                ✅ Cumplido
                Inferencia en Groq LPU con openai/gpt-oss-120b ejecutando extracción semántica (sentimiento, temas, insight y fórmula score_final = 0.75 × score_llm + 0.25 × peso_tipo) en formato JSON estricto.
              

              

                3. Generación de ≥ 2 formatos de marketing
                ✅ Cumplido
                3 formatos implementados simultáneamente: Post de LinkedIn con ganchos/hashtags, FAQ Técnico estructurado y Newsletter Semanal.
              

              

                4. Orquestación del flujo en n8n
                ✅ Cumplido
                Pipeline modular n8n compuesto por WF1 (24 nodos), WF2 (14 nodos) y WF3 (8 nodos), con switch condicional, merges, prompts especializados y control de excepciones.
              

              

                5. Persistencia en OCI Object Storage Always Free
                ✅ Cumplido
                Convención en OCI Bucket: activos/aprobados/{execution_id}/{asset_id}.json mediante llamadas REST HTTP PUT autenticadas con Pre-Authenticated Request (PAR) al aprobar mediante WF2 en n8n (no requerido en Netlify ni frontend).
              

              

                6. Demostración de ≥ 3 ejemplos de transformación
                ✅ Cumplido
                Dataset de prueba con 4 interacciones cubriendo las 3 ramas activas (testimonio, duda técnica, logro) y el caso de auditoría de descarte (motivo tipo_no_elegible).
              

              

                7. Documentación y diagrama del pipeline
                ✅ Cumplido
                Documentación exhaustiva en README.md, contratos de datos formalizados, diagramas de arquitectura y credenciales centralizadas.
              

              

                Diferencial: Curaduría Humana (Human-in-the-Loop)
                ⭐ Destacado
                Doble interfaz: Streamlit Cloud en producción v2.2 (app.py) + Portal Web interactivo en Netlify conectado a Google Sheets con escritura atómica.
              

              

                Diferencial: Observabilidad Diaria & Power BI
                ⭐ Destacado
                Workflow WF3 con consolidación diaria hacia Google Sheets y reporte analítico de 2 páginas en Power BI Desktop (CommunityLab_Dashboard.pbix) con regla DAX MAX(fecha).
